# Журнал изменений PulseDeck

Здесь записано, что менялось в программе PulseDeck для Windows от версии к версии.
Новое сверху. Формат — по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
номера версий — по [семантическому версионированию](https://semver.org/lang/ru/).

Приложения для телефона ведут свои журналы в своих репозиториях:
[PulseDesk](https://github.com/kirdev07/PulseDeck-Mobile--KirDev-Software) и
[PulseDeck Panel](https://github.com/kirdev07/PulseDeck-Panel_Kirdev-Software).

## [1.0.4] — 2026-11-22

### Добавлено
- Панель PulseDeck Panel получает список приложений с музыкой и может выбрать, чей трек показывать
  и кем управлять (команда `source`), и видит, что сейчас открыто на ПК (сообщения `sessions` и
  `activity`, см. `docs/PANEL_PROTOCOL.md`). Старые панели эти сообщения пропускают.
- **«Оформление» → Фон окна → Mica** (Windows 11 22H2 и новее): материал Windows 11, сквозь окно
  чуть видны обои рабочего стола.
- Окно плавно появляется при запуске (выключается вместе с анимациями).
- Веб-панель: **«Настройки → Экран → Частота кадров»** — экономно 30, плавно 60 или максимум
  (каждый кадр экрана 90/120 Гц); раньше анимации были всегда около 30 кадров.

### Изменено
- Пока окно в трее или свёрнуто, показатели снимаются раз в 3 секунды вместо каждой секунды
  (меньше нагрузка на процессор); график на главной при этом не теряет времени.

### Исправлено
- Файл настроек, сохранённый с меткой BOM (например, Блокнотом или PowerShell), больше не
  сбрасывает оформление и настройки к значениям по умолчанию.
- Скриншот с телефона и из веб-панели снимает главный монитор, а не все мониторы одной полосой.

## [1.0.3] — 2026-11-21

### Добавлено
- **Новый дизайн программы в стиле Material 3**: боковая панель с выделением «таблеткой» и
  кнопкой «Подключить телефон», карточки без рамок со скруглением 24, кнопки-таблетки,
  переключатели Material 3, графики и главная плитка в цвете акцента, скруглённые углы окна
  (Windows 11), фон окна со свечением акцента.
- **«Настройки → Оформление»**: стиль (цветной или чёрно-белый, как раньше), режим (тёмный,
  светлый, как в Windows), чёрный фон AMOLED, 5 цветов акцента, фон окна (свечение, точки,
  ровный). «Применить» перезапускает окно за пару секунд.
- **Новый логотип** «ПК и телефон» — в программе, трее, установщике и веб-панели.
- **Веб-панель** — экран PulseDeck Panel в браузере любого телефона, iPhone и Android, без
  установки приложения. Включается в «Настройки» → «Веб-панель».
  - Подключение по 6-значному коду или QR-коду с экрана «Телефон», телефон запоминается.
    На экране «Телефон» выбирается, что подключаем: приложение или браузер.
  - Защищённый режим (HTTPS) с домашним сертификатом ПК: профиль для iPhone, файл для
    Android. Браузер, подключённый по HTTPS, получает «Полный» доступ.
  - Часы, загрузка процессора, видеокарты, памяти, сеть, диски, батарея и время работы ПК,
    что сейчас открыто на ПК.
  - Плеер: обложка, перемотка, громкость ПК, выбор приложения с музыкой; ползунок трека
    волной и полоски «играет», цвета из обложки, жесты по карточке плеера.
  - Плеер на экране блокировки и в Пункте управления iPhone: трек ПК с обложкой, пауза,
    переключение и перемотка.
  - **«Управление ПК»** — экраны приложения PulseDesk: выключение и перезагрузка с таймером,
    сон, блокировка, окна, программы, сценарии, сайт и поиск, скриншот, громкость; файлы
    (скачать, отправить на ПК, переименовать, новая папка, в корзину), процессы, события.
    Только в защищённом режиме с доступом «Полный»; опасные действия спрашивают подтверждение.
  - Предупреждения с собственными порогами (процессор, видеокарта, память, видеопамять,
    диск, батарея) и уведомления на телефон, в том числе при закрытой панели (Web Push).
  - Оформление: тёмная и белая тема (и по времени суток), 7 цветов акцента, фон, цвет и
    10 шрифтов часов, 4 раскладки, свои плитки внизу с мини-графиками и подробностями,
    30 анимаций, защита от выгорания, «не гасить экран».
  - Настройки разделены на страницы: Оформление, Часы, Плеер, Плитки, Предупреждения,
    Анимации, Экран, Подключение.
  - Открытая страница сама перезагружается, когда на ПК обновилась веб-панель.

### Исправлено
- Окно установщика «Разрешить этому приложению вносить изменения?» (UAC) больше не
  считается блокировкой ПК: управление с телефона и бота работает, ложных сообщений
  «Компьютер заблокирован» нет.
- Отозванная панель или браузер получают «доступ отозван», а не обрыв связи.

### Безопасность
- Защита от подмены адреса (DNS rebinding): сервер для телефонов и веб-панель отвечают только
  по IP-адресу ПК, `localhost` или имени компьютера, а не по имени чужого сайта.
- Имя телефона при подключении сохраняется одной строкой: им больше нельзя подделать строки в
  журнале или текст в окне подтверждения.
- Имя файла, отправленного с телефона, очищается от `:` и служебных символов (скрытые потоки
  NTFS больше не создаются).
- Уведомления веб-панели — только браузерам, подключённым по HTTPS, и только через push-сервисы
  браузеров (Apple, Google, Mozilla, Microsoft).
- Telegram-бот не выполняет события без отправителя (закрыт по умолчанию).
- **Старый протокол без шифрования (v0) выключен** — и по умолчанию, и один раз у тех, у кого он
  был включён. PulseDesk и PulseDeck Panel работают по защищённому протоколу (TLS); телефон,
  подключённый по старому протоколу, подключается заново по коду. Включить можно в
  «Настройки → Телефон».
- **Новый домашний сертификат веб-панели**: теперь он ограничен и для имён сайтов, не только для
  IP-адресов — даже с украденным ключом им нельзя подделать настоящий сайт. Старый сертификат
  заменяется автоматически; на телефоне нужно один раз удалить старый профиль/сертификат
  PulseDeck и установить новый со страницы `http://<IP ПК>:8780`.
- **Подключение браузера без шифрования — только для просмотра.** ПК показывает два кода:
  основной (приложения, браузер по HTTPS) и «Только просмотр» (страница по HTTP). Код,
  отправленный без шифрования, нельзя использовать для полного доступа, а основной код,
  введённый на незащищённой странице, сразу отменяется.
- Политика конфиденциальности дополнена веб-панелью, уведомлениями, проверкой обновлений и
  настоящим местом хранения данных (`%APPDATA%\PulseDeck`).

## [1.0.2] — 2026-10-28

### Изменено
- QR-код подключения на экране «Телефон» — постоянного размера 240 px, а не на всю карточку.
- Ссылки на репозитории приложений обновлены после их переименования на GitHub.

## [1.0.1] — 2026-10-28

### Добавлено
- Снова подключение телефона по QR-коду.
- Обновление скачивается сразу и предлагает установиться, без лишних шагов.

## [1.0.0] — 2026-10-26

Первая версия под именем PulseDeck.

### Добавлено
- Новый интерфейс: главная с живой загрузкой, Telegram-бот, телефон, приложения, консоль,
  музыка, настройки.
- Telegram-бот с карточкой профиля и отправкой файлов с ПК.
- Приложения для телефона: API по TLS с закреплённым сертификатом и подключением по коду,
  доступ отдельно для каждого устройства, панель PulseDeck Panel (в том числе по USB).
- Токен бота хранится зашифрованным (Windows DPAPI); сервер для телефонов отвечает только
  домашней сети.
- Установщик для Windows, портативный ZIP, установка одной командой PowerShell,
  автообновление из GitHub Releases.
- Политика конфиденциальности, условия использования, сторонние лицензии.
