# Политика конфиденциальности PulseDeck

Обновлено: 25 октября 2026 года. Относится к PulseDeck 1.0 (прежнее название — Pulse-PC).

Документ описывает, какие данные обрабатывает программа, где они хранятся и куда передаются.
Он составлен по исходному коду программы. Если поведение программы изменится, документ будет
обновлён.

## Коротко

- PulseDeck работает на вашем компьютере и **не отправляет данные разработчику**: в программе нет
  телеметрии, аналитики, рекламы и автоматической проверки обновлений.
- Данные уходят с компьютера только туда, куда вы сами их направляете: в ваш Telegram-бот и на
  ваши телефоны в локальной сети.
- Все настройки, журналы и полученные файлы хранятся на вашем компьютере.

## Что хранится на компьютере

Всё лежит в папке программы: `config/` и `files/`.

| Данные | Файл | Срок хранения |
|---|---|---|
| Токен Telegram-бота | `config/secrets.bin`, зашифрован средствами Windows (DPAPI) для вашей учётной записи | пока вы его не удалите или не замените |
| Ваш Telegram ID (администратор) | `config/.env` | пока вы его не измените |
| Список программ для быстрого запуска | `config/programs.json` | пока вы его не измените |
| Настройки меню бота, сценарии, уведомления | `config/bot_options.json` | пока вы их не измените |
| Подключённые телефоны: имя, дата добавления, время последней связи | `config/local_api.json` | до отзыва доступа на экране «Телефон» |
| Ключи доступа телефонов | там же, **только в виде хэша SHA-256**: сам ключ хранится лишь на телефоне | до отзыва доступа |
| Сертификат для защищённого подключения телефонов | `config/tls/` (закрытый ключ зашифрован) | постоянно |
| Папки музыкальной библиотеки | `config/player.json` | пока вы их не измените |
| История передачи файлов: имя, путь, направление, результат, время | `config/transfers.json` | последние 100 записей |
| Журнал событий | `config/logs/pulse.log` | до 4 файлов по 2 МБ, старые записи вытесняются |
| Файлы, присланные с телефона или из Telegram | `files/` | файлы старше 3 дней удаляются при каждом запуске Telegram-бота; если бот не используется — пока вы не удалите их сами |
| Настройки интерфейса | `config/app_settings.json` | пока вы их не измените |

Токен бота в журнале скрывается. Скриншоты не сохраняются на диск: они создаются в памяти и
сразу отправляются по вашему запросу.

## Куда передаются данные

### Telegram

Работает, только если вы настроили и запустили бота. Программа обращается к официальному Bot API
(`api.telegram.org`). В ваш чат с ботом уходят:
- ответы на ваши команды: состояние ПК, список окон и программ, история передач;
- скриншоты и файлы, которые вы запросили;
- уведомления: о запуске программы, блокировке ПК и, если вы их включили, о высокой нагрузке и
  нехватке места на диске.

Бот выполняет команды только от одного Telegram ID — администратора. Сообщения других
пользователей отклоняются; в журнал записываются их ID и имя пользователя.

Эти данные проходят через серверы Telegram и обрабатываются по
[политике конфиденциальности Telegram](https://telegram.org/privacy).

### Телефоны в локальной сети (Pulse Mobile)

Сервер PulseDeck отвечает только устройствам вашей локальной сети. Запросы из интернета
отклоняются, даже если порт проброшен на роутере. Подключённый телефон может получать состояние
ПК, скриншоты, списки файлов, папок и окон, сами файлы, а также управлять программами, питанием,
звуком и плеером.

- **Защищённый протокол (TLS, версия 1):** данные между телефоном и ПК шифруются.
- **Старый протокол (HTTP, версия 0):** данные передаются **без шифрования** и могут быть
  перехвачены в той же сети. Он включён по умолчанию для совместимости с текущей версией
  Pulse Mobile; выключите его в «Настройки → Телефон», когда все телефоны перейдут на
  подключение по коду.

Для поиска ПК в сети телефон отправляет широковещательный запрос, а ПК отвечает своим именем
и портами.

### Браузер

По вашей команде из Telegram или с телефона ПК открывает в браузере ссылку или поиск Google.
Дальше эти сайты обрабатывают данные по своим правилам.

### Диагностика

Кнопка «Запустить проверку» на экране «Консоль» проверяет, доступен ли `api.telegram.org`
(DNS и соединение с портом 443). Никакие данные при этом не отправляются.

## Чего PulseDeck не делает

- не собирает статистику использования и сведения об ошибках;
- не отправляет журналы, скриншоты или файлы разработчику;
- не передаёт данные рекламным сетям и третьим лицам;
- не открывает доступ к ПК из интернета.

Раздел «Поддержка» сейчас только ведёт на страницу проекта на GitHub. Если в будущем появится
отправка обращений из программы, журналы и скриншоты будут прикладываться только после вашего
явного согласия в каждом обращении, и этот документ будет обновлён заранее.

## Ваши возможности

- Отозвать доступ телефона: «Телефон → Отозвать».
- Запретить новые подключения: «Телефон → Разрешить новые подключения».
- Остановить бота или удалить токен: экраны «Telegram Бот» и «Настройки».
- Очистить историю и журналы: удалить файлы `config/transfers.json` и `config/logs/`.
- Удалить все данные: удалить папки `config/` и `files/` вместе с программой.

## Безопасность

PulseDeck выполняет действия с правами вашей учётной записи Windows. Используйте отдельного
Telegram-бота, никому не передавайте его токен и подключайте только свои телефоны. Сверяйте
отпечаток сертификата при подключении по коду.
