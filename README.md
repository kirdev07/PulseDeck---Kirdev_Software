# Pulse-PC

**Управляйте своим Windows-компьютером из окна программы, через Telegram и с телефона в домашней сети.**

## О проекте

**Pulse-PC** — панель управления компьютером: мониторинг системы, программы, файлы, мультимедиа,
личный Telegram-бот и локальный сервер для мобильного приложения **Pulse Mobile**.

Версия **2.0 (Fusion)** — новый интерфейс в стиле AMOLED Black и установщик со встроенным Python:
ставить Python и пакеты отдельно не нужно.

> **Важно:** Pulse-PC выполняет действия с вашим компьютером удалённо. Используйте его только на своём
> ПК, храните токен бота в секрете и подключайте только свои телефоны.

## Возможности

### Программа на ПК

| Экран | Что есть |
| --- | --- |
| **Главная** | CPU, RAM, GPU, диски, сеть, время работы, батарея — только реальные данные или «Недоступно»; состояние Telegram и телефона; мини-плеер |
| **Telegram Бот** | запуск, остановка, перезапуск; состояние связи и понятные ошибки; счётчики команд и отказов; отправка файлов с ПК в Telegram с прогрессом; меню, сценарии и уведомления; журнал бота |
| **Телефон** | сервер для Pulse Mobile; адреса для подключения; подключение по коду (TLS); список телефонов с отзывом доступа; история передачи файлов |
| **Приложения** | список программ для быстрого запуска (общий с Telegram и телефоном), нагрузка CPU/RAM запущенных, поиск, фильтры, запуск и завершение |
| **Консоль** | журнал по источникам, фильтры уровней, поиск, экспорт; диагностика настроек, связи с Telegram и портов |
| **Музыка** | встроенный плеер с очередью, перемешиванием и повтором, библиотека, обложки; управление плеерами других приложений |
| **Настройки** | автозапуск, анимации, Telegram, телефон, сводка безопасности, политика конфиденциальности, лицензия, сторонние компоненты |

Окно закрывается в трей: бот и сервер для телефона продолжают работать. Telegram и сервер для
телефона независимы — остановка или ошибка бота не отключает телефон.

### Управление через Telegram

| Раздел | Что можно делать |
| --- | --- |
| **Система** | Блокировать ПК, переводить в сон, выключать и перезагружать с подтверждением |
| **Таймер** | Назначать и отменять отложенное выключение или перезагрузку |
| **Программы** | Запускать настроенные приложения и завершать процессы |
| **Сценарии** | Запускать заранее сохранённые наборы программ |
| **Окна** | Просматривать открытые окна, сворачивать, разворачивать и выводить на передний план |
| **Файлы** | Просматривать папки и диски, отправлять файлы в Telegram и принимать вложения на ПК |
| **История файлов** | Смотреть последние передачи и повторять неудачные отправки |
| **Экран** | Получать скриншоты с выбором монитора |
| **Мультимедиа** | Переключать треки, ставить на паузу, менять громкость и отключать звук |
| **Информация** | Запрашивать состояние компьютера |
| **Поиск и ссылки** | `/search`, `/s` или `? запрос` — поиск в браузере; ссылки из сообщений открываются на ПК |
| **Избранное** | Часто используемые действия и программы над основным меню |
| **Уведомления** | Оповещения о нагрузке CPU, свободном месте и завершении отслеживаемых процессов |

- Файлы **с ПК в Telegram — до 50 МБ**, из Telegram на ПК — **до 20 МБ**.
- История хранит **последние 100 передач**; избранное — **до 6** элементов; **до 20 сценариев** по **15 программ**.
- Таймер питания требует подтверждения, максимум **1440 минут**.
- Бот отвечает только администратору (вашему Telegram ID). Пока ПК заблокирован, управление запрещено.

Все команды: **[BOT_GUIDE.md](BOT_GUIDE.md)**.

### Pulse Mobile — управление ПК с Android

**[Pulse Mobile Client](https://github.com/kirdev07/Pulse-Mobile-Client)** — отдельное приложение на
Kotlin для Android 11+. С телефона доступны: состояние ПК, питание и таймер, программы, сценарии, окна,
файлы (в обе стороны), музыка с управлением из уведомлений, скриншоты, поиск и ссылки, несколько ПК.

**Как подключить:**

1. Установите Pulse-PC и откройте экран **«Телефон»** — сервер запускается автоматически.
2. Подключите ПК и телефон к одной Wi-Fi-сети.
3. В Pulse Mobile найдите ПК (поиск по UDP) или введите адрес с экрана «Телефон».
4. Подтвердите подключение на ПК. Телефон получает собственный ключ; отозвать его можно на экране
   «Телефон» (удаление ПК в приложении ключ не отзывает).

**Протоколы.** Текущая версия Pulse Mobile использует **API v0 по HTTP без шифрования** (порт 8765).
Pulse-PC 2.0 уже поддерживает **API v1 по TLS** (порт 8767) с подключением по 6-значному коду и сверкой
отпечатка сертификата; поддержка в Android-клиенте ожидается. Описание протокола:
[docs/PULSE_MOBILE_API_V1.md](docs/PULSE_MOBILE_API_V1.md). Когда все телефоны перейдут на v1, выключите
старый протокол в «Настройки → Телефон».

### Безопасность

- Сервер для телефона отвечает **только устройствам локальной сети** — запросы из интернета отклоняются,
  даже если порт проброшен на роутере.
- У каждого телефона свой ключ; на ПК хранится только его хэш SHA-256; доступ отзывается в один клик.
- Токен бота **зашифрован средствами Windows (DPAPI)** для вашей учётной записи.
- Бот выполняет команды только от вашего Telegram ID и пишет в журнал попытки посторонних.
- В программе нет телеметрии; данные никуда, кроме вашего бота и ваших телефонов, не отправляются.

Подробнее: [Политика конфиденциальности](PRIVACY_POLICY.md) · [Условия использования](TERMS_OF_USE.md) ·
[Обзор безопасности 1.0](SECURITY_REVIEW_1_0.md).

## Установка

1. Скачайте **`Pulse-PC-<версия>-Setup.exe`** со страницы
   **[GitHub Releases](https://github.com/kirdev07/Pulse-PC/releases)**.
2. Запустите. Права администратора не нужны: программа ставится для текущего пользователя.
3. Откройте **Настройки → Telegram Бот**, укажите токен от @BotFather и свой Telegram ID, сохраните.
4. На экране **«Telegram Бот»** нажмите «Запустить» и отправьте боту `/start`.

Обновление — тот же установщик поверх. Удаление — «Параметры Windows → Приложения». Настройки хранятся в
`%APPDATA%\Pulse-PC` и сохраняются при обновлении. Подробно, включая переход с 1.x:
**[УСТАНОВКА.md](УСТАНОВКА.md)**.

Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может показать предупреждение
«Неизвестный издатель».

## Для разработчиков

```powershell
git clone https://github.com/kirdev07/Pulse-PC.git
cd Pulse-PC
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt -r requirements-optional.txt
.venv\Scripts\python -m pulse_pc
```

При запуске из исходников данные лежат в `config/` и `files/` рядом с кодом. Двойной щелчок по
`PulsePC.pyw` запускает программу без консоли.

Тесты (Telegram проверяется на локальном имитаторе Bot API, сеть не нужна):

```powershell
.venv\Scripts\python -m unittest discover -s tests
```

Сборка установщика: [docs/BUILD.md](docs/BUILD.md).

## Частые вопросы

**Нужен ли Python?** Нет, он встроен в установщик. Python нужен только для запуска из исходников.

**Работает ли телефон без Telegram?** Да. Сервер для телефона не зависит от бота.

**Почему не подключается телефон?** ПК и телефон должны быть в одной сети; сервер должен быть запущен
(экран «Телефон»); брандмауэр Windows должен разрешать Pulse-PC доступ к частной сети; в роутере не
должна быть включена изоляция клиентов Wi-Fi. Кнопка «Запустить проверку» на экране «Консоль»
проверяет порты.

**Бот пишет «уже получает обновления в другом месте».** Запущена вторая копия программы с тем же ботом
или у бота настроен webhook. Остановите другую копию.

**Linux или macOS?** Нет, Pulse-PC использует функции Windows.
