# Сборка установщика Pulse-PC

Один файл `Pulse-PC-<версия>-Setup.exe` со встроенным Python и всеми библиотеками. Пользователю
не нужно ставить Python и запускать `pip`.

## Как собрать

Нужны (только для сборки, пользователям не поставляются):

```
.venv\Scripts\python -m pip install -r requirements.txt -r requirements-optional.txt -r requirements-build.txt
winget install JRSoftware.InnoSetup
```

Сборка:

```
.venv\Scripts\python packaging\build.py
```

Результат: `dist\Pulse-PC\` (папка программы) и `dist\Pulse-PC-<версия>-Setup.exe`.
`--no-installer` — только папка программы.

## Из чего состоит

| Файл | Назначение |
|---|---|
| `packaging/pulse_pc.spec` | PyInstaller: одна папка (`Pulse-PC.exe` + `_internal/`), без консоли, без UPX |
| `packaging/installer.iss` | Inno Setup: установка, ярлыки, автозапуск, обновление, удаление |
| `packaging/version_info.txt` | сведения о версии в свойствах `Pulse-PC.exe` |
| `packaging/build.py` | запускает оба шага и печатает размеры |

## Размер (Windows 11, Python 3.14, PySide6 6.12)

| Вариант | Папка программы | Установщик |
|---|---|---|
| PyInstaller без исключений | 190 МБ | — |
| С исключениями | 139 МБ | 44,1 МБ (LZMA2) |
| Без PyAutoGUI и старой панели (текущий) | 136 МБ | **43,2 МБ** |

Что исключено и почему это безопасно:
- модули Qt, которые не импортирует ни один файл Pulse-PC: WebEngine, QML/Quick, 3D, Charts,
  PDF, Designer, SQL, Bluetooth и т. п.; их DLL и плагины;
- переводы Qt, кроме русского и английского;
- `tkinter` (нужен только старому самоустановщику `PulsePC.pyw`), `pydoc`, `test`, `lib2to3`.

`unittest` **оставлен**: aiogram импортирует `unittest.mock` при запуске. Без него собранная
программа запускалась, но фоновые службы падали — это выявил пробный запуск, поэтому каждый
вариант сборки проверяется запуском (см. ниже).

Крупнее всего остаются Qt (≈40 МБ) и кодеки FFmpeg для встроенного плеера (≈20 МБ), Pillow для
скриншотов (13 МБ) и `cryptography` для TLS (10 МБ). Nuitka не проверялась: нужен компилятор C,
а выигрыш в размере установщика для такой программы обычно невелик.

## Установка

- Для текущего пользователя, без прав администратора: `%LOCALAPPDATA%\Programs\Pulse-PC`.
- Данные пользователя: `%APPDATA%\Pulse-PC` (настройки, токен, телефоны, журнал, полученные файлы).
  Переопределяется переменной `PULSE_PC_DATA_DIR`.
- Задачи установщика: ярлык на рабочем столе, автозапуск с Windows (выключен по умолчанию).
- Обновление: тот же установщик поверх старой версии. Запущенная программа закрывается,
  старая папка `_internal` удаляется, данные в `%APPDATA%` не трогаются.
- Удаление: «Параметры → Приложения» или ярлык «Удалить Pulse-PC». Удаляются программа,
  ярлыки и запись автозапуска; затем установщик спрашивает, удалять ли данные (по умолчанию —
  нет). При тихом удалении (`/VERYSILENT`) данные сохраняются.

Переход с версии 1.x (ZIP с исходниками): её данные лежат в папке `config/` рядом со старой
программой. Чтобы перенести настройки, скопируйте содержимое `config/` в
`%APPDATA%\Pulse-PC\config\` до первого запуска новой версии.

## Проверка сборки

Проверено 25.10.2026 на собранном установщике (повторно после очистки этапа G — те же результаты, в журнале ошибок нет):

| Проверка | Результат |
|---|---|
| Тихая установка во временную папку, задача «автозапуск» | код 0; 158 файлов, 143 МБ; запись в «Приложениях», ярлык в «Пуске», значение автозапуска с путём к exe |
| Запуск установленной программы | окно отрисовывается, метрики реальные; API v0 (`/api/ping`) и v1 TLS (`/api/v1/info`) отвечают; без ключа — 401; токен и сертификат создаются в папке данных |
| Обновление поверх запущенной программы | код 0; программа закрыта Restart Manager; данные пользователя сохранены |
| Тихое удаление | код 0; удалены папка, автозапуск, запись в «Приложениях», ярлыки; процесс завершён; данные сохранены |

Не проверено автоматически: вопрос об удалении данных при обычном (не тихом) удалении,
работа на «чистой» Windows без установленного Python, Windows 10.
