Обновлено: 25 октября 2026 года. Ветка `fusion-2.0`, в `main` не слита.

## Нужны решения владельца

| Вопрос | Варианты | Сейчас |
|---|---|---|
| Доступ к файлам с телефона и из Telegram | весь диск / только выбранные папки (список в «Настройках») | открыт весь диск, как в 1.x |

## Нужна проверка владельцем (до выпуска)

- [ ] Настоящий Telegram-бот с вашим токеном: запуск, `/start`, команды, скриншоты, файлы в обе стороны, таймер выключения, сценарии, уведомления.
- [ ] Режим настройки: бот без ID администратора отвечает вашим ID и ничего не выполняет.
- [ ] Pulse Mobile на телефоне (старый протокол v0): поиск ПК, подключение, все разделы, отзыв доступа.
- [ ] Интерфейс мышью: перетаскивание и размер окна, трей, закрытие в трей, диалоги.
- [ ] Обычное (не тихое) удаление: вопрос «Удалить также настройки?».
- [ ] Установка на чистой Windows без Python, желательно и на Windows 10.
- [ ] Перенос настроек с 1.x по инструкции из `УСТАНОВКА.md`.

## Ждёт других проектов

- **Pulse Mobile: поддержка API v1 (TLS).** На ПК готово, протокол описан в `docs/PULSE_MOBILE_API_V1.md`. Пока клиент не обновлён, связь с телефоном идёт по HTTP без шифрования. После перехода всех телефонов выключить старый протокол в «Настройки → Телефон».
