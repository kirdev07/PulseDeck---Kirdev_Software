# PulseDeck Panel ↔ PulseDeck: протокол дисплея (v1)

PulseDeck Panel — Android-приложение, превращающее телефон в информационный дисплей ПК: часы,
показатели CPU/GPU/RAM/дисков, текущий трек с управлением.

Протокол построен на **API v1** ([PULSE_MOBILE_API_V1.md](PULSE_MOBILE_API_V1.md)) и не вводит
отдельный сервер: тот же порт TLS 8767, тот же поиск ПК по UDP 8766, то же сопряжение по коду с экрана
«Телефон» и те же отзываемые ключи устройств. Pulse Mobile и Panel могут работать одновременно.

## Подключение

1. Поиск: UDP-broadcast `PULSEPC?` на порт 8766, ответ содержит `tls_port`.
2. Сопряжение (один раз): `POST https://<ip>:8767/api/v1/pair` `{"device": "PulseDeck Panel", "code": "123456"}`
   → `{"token": "…"}`. Телефон закрепляет SHA-256 отпечаток сертификата ПК и показывает его короткую
   форму для сверки с экраном ПК.
3. Дисплей: `GET wss://<ip>:8767/api/v1/display` с заголовком `Authorization: Bearer <token>`.
   Сертификат должен совпадать с закреплённым отпечатком, иначе клиент не отправляет ключ.

Без ключа или с отозванным ключом — `401` до установки WebSocket. Запросы не из локальной сети — `403`.

QR-код на ПК («Телефон» → «Подключить по коду»):
`pulsedeck://pair?v=1&name=<ПК>&hosts=<ip,ip>&port=8767&fp=<SHA-256 hex>&code=<6 цифр>`.
Телефон закрепляет `fp` из QR — сверка глазами не нужна.

## Сообщения ПК → телефон

```json
{"type": "hello", "protocol": 1, "app": "PulseDeck", "name": "DESKTOP-1",
 "metrics_interval": 1.5, "commands": ["next", "prev", "seek", "toggle", "volume"]}
```

Каждые 1,5 с:

```json
{"type": "metrics",
 "cpu": {"load": 24.0, "temp": null, "name": "13th Gen Intel(R) Core(TM) i5-13420H", "cores": 12, "per_core": [12.5, 30.1]},
 "gpu": {"load": 38.0, "temp": null, "name": "NVIDIA GeForce RTX 3050 6GB Laptop GPU",
         "memory_total": 6442450944, "memory_used": 812000000},
 "ram": {"percent": 46.0, "used": 7900000000, "total": 17000000000},
 "net": {"down": 1250000, "up": 98000},
 "uptime": 86400,
 "disks": [{"name": "C:", "label": "Windows", "total": 512000000000, "free": 312000000000}]}
```

`null` — значение недоступно (датчика нет, счётчик не поддерживается). Температуры пока всегда `null`:
Windows не даёт их без сторонних драйверов. Диски — фактические тома, без деления на SSD/HDD.

При смене трека или состояния, а во время воспроизведения ещё и каждые 5 с (сверка позиции):

```json
{"type": "media", "session": {"title": "After Dark", "artist": "Mr.Kitty", "album": "",
 "status": "playing", "position": 42.0, "duration": 208.0, "source": "Spotify",
 "cover": "<ключ>", "can_prev": true, "can_next": true}}
```

В каждом `media` есть `"system_volume": {"level": 35, "muted": false}` (или `null` без pycaw);
изменение громкости тоже приводит к новому сообщению.

`"session": null` — ничего не играет (показывается волна). `status` — `playing` или `paused`; пока
сессия на паузе, она остаётся. Между сообщениями телефон сам продвигает позицию. Обложка:
`GET /api/v1/player/cover?key=<ключ>` с тем же ключом устройства; пустой `cover` — обложки нет.
Источники — встроенный плеер PulseDeck и медиасессии Windows (GSMTC: Spotify, Яндекс Музыка,
браузеры и др.). Полнота метаданных, обложки и управления зависят от приложения-источника.

Ошибки: `{"type": "error", "code": "locked" | "bad_command" | "bad_message" | "player", "message": "…"}`.
`pong` — ответ на `ping`.

Закрытие с кодом **4001** — доступ отозван на ПК; телефон удаляет ключ и предлагает новое сопряжение.

## Сообщения телефон → ПК

```json
{"type": "command", "action": "toggle"}   // toggle | next | prev
{"type": "command", "action": "seek", "value": 42.5}     // позиция трека, секунды
{"type": "command", "action": "volume", "value": 35}     // громкость ПК 0..100 (нужен pycaw)
{"type": "ping"}
{"type": "subscribe", "metrics": false}   // приложение ушло в фон: только трек, без метрик
{"type": "subscribe", "interval": 3}      // период метрик 1..10 с
```

Любые другие команды отклоняются. Пока ПК заблокирован, показатели и трек передаются, команды — нет.

Видеокарта — с наибольшим объёмом памяти (в ноутбуке — дискретная); `load` — самый загруженный
движок среди всех видеокарт, как в «Диспетчере задач». `net` — байт/с по всем сетевым адаптерам.

## Подключение по USB

* **adb reverse** (на телефоне включена отладка по USB, на ПК есть Android platform-tools): PulseDeck
  сам выполняет `adb reverse tcp:8767 tcp:8767`, телефон подключается к `wss://127.0.0.1:8767`.
  Тот же TLS, отпечаток и ключ устройства.
* **USB-модем**: телефон и ПК получают общую частную сеть по кабелю; обычный поиск по UDP находит ПК.

## Версии

`protocol` в `hello` растёт только при несовместимых изменениях. Новые поля добавляются без смены
версии; клиент обязан игнорировать неизвестные поля и типы сообщений.
