# PulseDeck: установка и настройка

Нужна Windows 10 или 11 (64-бит). Python ставить не нужно — он встроен в установщик.

## 1. Установка

Три способа — выберите любой.

### Способ А: одной командой (без предупреждений Windows)

Нажмите Win+X → «Терминал» (или PowerShell) и вставьте:

```powershell
irm https://raw.githubusercontent.com/kirdev07/PulseDeck---Kirdev_Software/main/install.ps1 | iex
```

Скрипт ([install.ps1](install.ps1)) скачает установщик последней версии с GitHub и запустит его.
Дальше — как в способе Б с шага 3.

### Способ Б: установщик

1. Откройте страницу [Releases](https://github.com/kirdev07/PulseDeck---Kirdev_Software/releases/latest)
   и скачайте **`PulseDeck-1.0.0-Setup.exe`** (раздел «Assets»).
2. Запустите файл. Windows SmartScreen может написать «Windows защитила ваш компьютер»: установщик
   не подписан платным сертификатом. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Примите лицензию и выберите:
   - **Ярлык на рабочем столе** — по желанию;
   - **Запускать вместе с Windows** — PulseDeck будет стартовать свёрнутым в трей.
4. Нажмите «Установить». Права администратора не нужны: программа ставится в
   `%LOCALAPPDATA%\Programs\PulseDeck` для текущего пользователя.
5. В конце оставьте галочку «Запустить PulseDeck».

### Способ В: портативная версия (без установки)

1. Скачайте **`PulseDeck-1.0.0-Portable.zip`** со страницы
   [Releases](https://github.com/kirdev07/PulseDeck---Kirdev_Software/releases/latest).
2. Правый клик по ZIP → «Свойства» → отметьте **«Разблокировать»** → «ОК». Так Windows не будет
   предупреждать при запуске.
3. Распакуйте в любую папку и запустите `PulseDeck\PulseDeck.exe`.

Настройки хранятся там же, где у установленной версии (`%APPDATA%\PulseDeck`). Портативная версия
не обновляется сама: для новой версии скачайте новый ZIP и распакуйте поверх.

---

Если Windows спросит, разрешить ли PulseDeck доступ к сети, отметьте **частные сети** — это нужно
для телефона. Общедоступные сети отмечать не надо.

## 2. Telegram-бот

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и адрес бота.
   BotFather пришлёт **токен** вида `123456789:AA…` — скопируйте его целиком.
2. В PulseDeck: **Настройки → Telegram Бот** → вставьте токен → «Сохранить».
3. Экран **«Telegram Бот»** → «Запустить». Бот работает в режиме настройки.
4. Напишите своему боту `/start` — он ответит **вашим Telegram ID** (число).
5. Вставьте этот ID в **Настройки → Telegram Бот → ID администратора** и сохраните.
6. Нажмите «Перезапустить». На экране «Telegram Бот» появится карточка: аватарка бота и ваш
   профиль, а бот пришлёт приветствие с меню.

Чтобы у бота была аватарка и описание, задайте их в @BotFather (`/setuserpic`, `/setabouttext`),
затем перезапустите бота в PulseDeck.

Токен хранится зашифрованным средствами Windows и доступен только вашей учётной записи. Команды бот
выполняет только от вашего ID. Список команд: [BOT_GUIDE.md](BOT_GUIDE.md).

## 3. Телефон

Есть два приложения для Android 11+ (APK — в разделе «Releases» каждого репозитория):

- **[PulseDesk](https://github.com/kirdev07/PulseDeck-Mobile--KirDev-Software/releases/latest)** — управление ПК с телефона;
- **[PulseDeck Panel](https://github.com/kirdev07/PulseDeck-Panel_Kirdev-Software/releases/latest)** — второй экран у монитора.

Подключение:

1. Скачайте APK на телефон и откройте его. Android попросит разрешить установку из этого
   источника — разрешите.
2. Телефон и ПК — в одной сети Wi-Fi. Или подключите кабелем с включённой «Отладкой по USB»:
   PulseDeck сам переключит связь на кабель.
3. В приложении нажмите **«Автопоиск в сети»** и выберите компьютер (или введите IP с экрана «Телефон»).
4. На ПК: экран **«Телефон» → «Показать код»**. Сверьте отпечаток и введите 6 цифр на телефоне.

Подключённые телефоны видны на экране «Телефон». Там же каждому можно дать **полный доступ** или
**только просмотр**, а также отозвать доступ.

## 4. Автозапуск

**Настройки → Основные → «Запускать вместе с Windows»**. Программа стартует свёрнутой в трей.
Бот запускается вместе с программой, если включён переключатель на экране «Telegram Бот».

## Обновление

PulseDeck обновляется сам: при запуске (не чаще раза в 6 часов) он проверяет релизы на GitHub и,
если есть новая версия, показывает уведомление в трее. Откройте **Настройки → Обновления →
«Скачать и установить»**, затем «Установить и перезапустить» — программа закроется, поставит
новую версию и запустится снова. Проверить вручную — там же, кнопка «Проверить».

Можно и по-старому: скачать установщик новой версии и запустить его поверх. Настройки, токен, подключённые телефоны и журнал хранятся в `%APPDATA%\PulseDeck` и сохраняются.

## Переход с версии 1.x (ZIP с Python)

Версия 1.x хранила настройки в папке `config\` рядом с программой. Чтобы перенести их:

1. Закройте старую версию (значок в трее → «Выход») и выключите её автозапуск, если включали.
2. Установите PulseDeck, но **не запускайте**.
3. Скопируйте содержимое старой папки `config\` в `%APPDATA%\PulseDeck\config\`.
4. Запустите PulseDeck. Токен из `.env` будет зашифрован автоматически.

Старое приложение Pulse Mobile подключается по незашифрованному протоколу. Перейдите на PulseDesk и
выключите старый протокол в **Настройки → Телефон**.

## Удаление

«Параметры Windows → Приложения → PulseDeck → Удалить» или «Удалить PulseDeck» в меню «Пуск».
Удаляются программа, ярлыки и автозапуск. Затем установщик спросит, удалить ли данные из
`%APPDATA%\PulseDeck`; по умолчанию они остаются на случай повторной установки.

## Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| SmartScreen не даёт запустить установщик | «Подробнее» → «Выполнить в любом случае» |
| Бот не запускается | Экран «Telegram Бот» показывает причину. «Консоль» → «Запустить проверку» проверит токен, ID и связь с Telegram |
| Бот отвечает только вашим ID | Не задан ID администратора — шаг 5 раздела «Telegram-бот» |
| «Бот уже получает обновления в другом месте» | Закройте вторую копию PulseDeck или другой сервис с этим ботом |
| Нет аватарки в карточке бота | Аватарка не задана в @BotFather, или вы ни разу не писали боту — напишите `/start` и перезапустите бота |
| Телефон не находит ПК | Одна сеть Wi-Fi; разрешите PulseDeck в брандмауэре для частных сетей; отключите изоляцию клиентов в роутере; или подключите USB-кабель |
| «Порт занят» на экране «Телефон» | Другая программа заняла порт 8765/8767; «Консоль» → «Запустить проверку» покажет, какой |
| Программа не открывается | Проверьте значок в трее — она могла запуститься свёрнутой. Журнал: `%APPDATA%\PulseDeck\config\logs\pulse.log` |
