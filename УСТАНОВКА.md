# PulseDeck: установка и обновление

Нужна Windows 10 или 11 (64-бит). Python ставить не нужно — он встроен в установщик.

## Установка

1. Скачайте `PulseDeck-<версия>-Setup.exe` со страницы
   [GitHub Releases](https://github.com/kirdev07/Pulse-PC/releases).
2. Запустите его. Если Windows SmartScreen покажет «Неизвестный издатель», нажмите
   «Подробнее» → «Выполнить в любом случае»: установщик не подписан цифровой подписью.
3. Выберите, нужен ли ярлык на рабочем столе и запуск вместе с Windows. Права администратора не нужны:
   программа ставится в `%LOCALAPPDATA%\Programs\PulseDeck` для текущего пользователя.

## Первая настройка

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В PulseDeck: **Настройки → Telegram Бот** → токен и ваш числовой Telegram ID → «Сохранить».
   Свой ID можно узнать, написав боту `/start`: он ответит, что ID не настроен, и покажет его.
3. Экран **«Telegram Бот»** → «Запустить». Бот отправит приветствие.

Токен хранится зашифрованным средствами Windows и доступен только вашей учётной записи.

## Телефон (Pulse Mobile)

1. Установите [Pulse Mobile](https://github.com/kirdev07/Pulse-Mobile-Client) на Android.
2. Подключите телефон к той же Wi-Fi-сети, что и ПК.
3. В приложении найдите ПК и подтвердите запрос на компьютере. Подключённые телефоны видны и
   отзываются на экране **«Телефон»**.
4. Если Windows спросит про доступ PulseDeck к сети, разрешите **частные сети**.

## Автозапуск

**Настройки → Основные → «Запускать вместе с Windows»**. Программа стартует свёрнутой в трей.
Бот запускается вместе с программой, если он настроен (переключатель на экране «Telegram Бот»).

## Обновление

Запустите установщик новой версии. Работающая программа закроется сама. Настройки, токен,
подключённые телефоны и журнал хранятся отдельно, в `%APPDATA%\PulseDeck`, и сохраняются.

## Переход с Pulse-PC 1.x (прежнее название, ZIP с Python)

Pulse-PC 1.x хранил настройки в папке `config\` рядом с программой. Чтобы перенести их:

1. Закройте старую версию (значок в трее → «Выход») и удалите её ярлык автозапуска, если включали.
2. Установите PulseDeck, но **не запускайте**.
3. Скопируйте содержимое старой папки `config\` в `%APPDATA%\PulseDeck\config\`.
4. Запустите PulseDeck. Токен из `.env` будет автоматически зашифрован, а в файле останется заглушка.

Подключённые телефоны и список программ перенесутся вместе с `config\`. Старую папку можно удалить.

## Удаление

«Параметры Windows → Приложения → PulseDeck → Удалить» или ярлык «Удалить PulseDeck» в меню «Пуск».
Удаляются программа, ярлыки и автозапуск. Затем установщик спросит, удалять ли данные из
`%APPDATA%\PulseDeck`; по умолчанию они остаются, чтобы при повторной установке ничего не потерять.

## Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| Бот не запускается | Экран «Telegram Бот» показывает причину. «Консоль» → «Запустить проверку» проверит токен, ID и связь с `api.telegram.org` |
| «Бот уже получает обновления в другом месте» | Закройте вторую копию PulseDeck или другой сервис с этим ботом |
| Телефон не находит ПК | Одна сеть Wi-Fi; разрешите PulseDeck в брандмауэре для частных сетей; отключите изоляцию клиентов в роутере |
| «Порт занят» на экране «Телефон» | Другая программа заняла порт 8765/8767; «Консоль» → «Запустить проверку» покажет, какой |
| Программа не открывается | Проверьте значок в трее — она могла запуститься свёрнутой. Журнал: `%APPDATA%\PulseDeck\config\logs\pulse.log` |
